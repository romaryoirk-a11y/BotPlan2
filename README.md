# 📍 Telegram-бот «Напоминалка» (Python)
### Russian-language reminder bot with GPS location clarification — aiogram 3 + MongoDB + Render

Бот понимает напоминания **на русском языке** («завтра в 9 утра позвонить маме»,
«через 2 часа погулять», «каждый день в 8:00 зарядка») и умеет напоминать
**по геолокации** — когда вы приедете к сохранённой точке (уточняя ваше местоположение
кнопкой отправки GPS).

## Возможности
| Функция | Как использовать |
|---|---|
| Напомнить по времени | `в 15:30 выпить таблетки`, `завтра в 9 утра позвонить маме`, `через 30 минут чай` |
| Повторять каждый день | `каждый день в 8:00 зарядка` |
| Напомнить по месту (GPS) | `/geo [радиус_м]` → отправить геолокацию → прислать текст |
| Проверить, рядом ли место | отправить свою текущую геолокацию (кнопка 📍) |
| Список | `/list` или кнопка «📋 Список» |
| Удалить | `/delete <№>` |
| Часовой пояс | `/timezone 3` |
| Отменить | `/cancel` |

## Стек
- **Python 3.11**, [aiogram 3](https://docs.aiogram.dev) — Telegram Bot API
- **MongoDB Atlas** + motor (async драйвер) — хранение напоминаний и настроек
- **FastAPI + uvicorn** — health-эндпоинт `/healthz` для web-хелсинга на Render
- Встроенный асинхронный планировщик (tick каждые 30 с) — выдача напоминаний по времени

## Структура
```
main.py            # точка входа: FastAPI lifespan запускает бот + scheduler
render.yaml        # Blueprint для деплоя на Render
app/
  config.py        # переменные окружения
  db.py            # MongoDB (motor), коллекции reminders / users
  parser.py        # разбор русского текста: время + текст напоминания
  bot.py           # хендлеры aiogram (текст, команды, GPS-локация, кнопки)
  scheduler.py     # фоновая выдача напоминаний по времени
requirements.txt
```

## Локальный запуск
```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt

export BOT_TOKEN="123456:ABC..."          # токен от @BotFather
export MONGO_URI="mongodb+srv://user:pass@cluster0.xxxxx.mongodb.net"

python main.py
```

## Деплой на Render
1. Создайте бесплатный кластер в **MongoDB Atlas**, добавьте IP-разрешение `0.0.0.0/0`,
   скопируйте строку подключения (`MONGO_URI`).
2. Получите токен у [@BotFather](https://t.me/BotFather) (`BOT_TOKEN`).
3. Push репозитория на GitHub → Render → **New ➜ Blueprint** (подхватит `render.yaml`).
4. В появившихся полях введите `BOT_TOKEN` и `MONGO_URI`.
5. Web Service запускается командой `python main.py`, порт берётся из `PORT`
   (Render сам его задаёт), health-check — `/healthz`. Бот работает на long polling,
   поэтому внешний webhook не нужен — сервис просто должен «жить».

> Бесплатный план Render засыпает при бездействии; long-polling бота не даёт ему уснуть,
> но для надёжности рассмотрите план Starter.

## Как работает GPS-напоминание
Telegram не позволяет боту отслеживать местоположение в фоне. Поэтому схема такая:
1. `/geo 500` — задаёте точку (радиус 500 м), отправив свою геолокацию, затем текст.
2. Когда нужно проверить — жмёте кнопку «📍 Отправить мою геолокацию».
3. Бот считает расстояние по формуле гаверсинуса и, если вы внутри радиуса,
   присылает напоминание с кнопкой «✅ снять».
